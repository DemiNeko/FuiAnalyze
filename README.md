# НейроЦифра

[Открыть демонстрацию](https://demineko.github.io/FuiAnalyze/) · [Код на GitHub](https://github.com/DemiNeko/FuiAnalyze) · [Подготовиться к защите](DEFENSE.md)

Мини-проект по искусственному интеллекту: нарисуй цифру от 0 до 9 и посмотри, как сверточная нейросеть её распознаёт. Модель действительно обучена на MNIST. Вычисления выполняются на устройстве пользователя, без API-ключей и сервера машинного обучения.

## Что можно показать

- Рисование мышью, стилусом или пальцем; распознавание после каждого штриха.
- Оценки всех десяти классов, отмена штриха и очистка холста.
- 30 готовых примеров: первые три тестовых изображения каждого класса, без отбора по правильности ответа. Повторное нажатие на цифру переключает образец.
- Изображение 28 × 28, четыре реальные карты активаций и активации 64 нейронов.
- Объяснение обучения и ограничений, [сценарий защиты](DEFENSE.md).

## Запуск за минуту

Нужен Node.js 20 или новее. В папке проекта:

```sh
npm start
```

Открыть http://127.0.0.1:4173. Устанавливать npm-пакеты не требуется.

Чтобы получить проект на другом компьютере:

```sh
git clone https://github.com/DemiNeko/FuiAnalyze.git
cd FuiAnalyze
npm start
```

Альтернатива с Python:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

На Windows вместо `python` можно использовать `py`. Открывай сайт через HTTP, а не двойным щелчком по `index.html`: браузер должен загрузить файлы весов через `fetch`. Все рабочие ресурсы входят в проект, внешние CDN и шрифты не используются. Локальный показ работает без интернета после получения проекта.

## Публикация на GitHub Pages

1. Создай публичный репозиторий на GitHub, например `neurodigit`.
2. Загрузи файлы проекта в ветку `main`, включая скрытую папку `.github`. Папка `training/data` с исходным датасетом не нужна; она исключена из Git.
3. В репозитории открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Открой **Actions → Deploy NeuroDigit to GitHub Pages → Run workflow**. После следующих push в `main` публикация запускается автоматически.
5. Дождись успешного выполнения. Ссылка появится в **Settings → Pages** и в результате шага Deploy. Её можно отправить преподавателю и открыть с телефона.

При загрузке через Git (замени USERNAME и имя репозитория):

```sh
git init -b main
git add .
git commit -m "Add NeuroDigit AI mini project"
git remote add origin https://github.com/USERNAME/neurodigit.git
git push -u origin main
```

Публичная ссылка появится только после публикации — локальный адрес `127.0.0.1` доступен на твоём компьютере. Workflow публикует только файлы сайта и документацию, не исходный обучающий датасет.

Официальная инструкция: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Результат обучения

| Показатель | Значение текущей модели |
|---|---:|
| Обучение | 55 000 изображений |
| Валидация | 5 000 изображений |
| Независимый тест | 10 000 изображений |
| Эпох | 8 |
| Выбранная эпоха | 7, по лучшей валидационной точности |
| Точность на тесте | **98,42% — 9 842 / 10 000** |
| Параметров | 27 562 |
| Веса float32 | 110 248 байт |
| Seed | 42 |

Все метрики, история обучения, контрольные суммы и матрица ошибок сохранены в [`assets/model.json`](assets/model.json). После повторного обучения ориентируйся на этот файл: числа в таблице относятся к поставляемой версии.

## Как устроена сеть

```text
28×28×1 → Conv 3×3, 8 фильтров → ReLU → MaxPool 2×2
26×26×8 → 13×13×8
        → Conv 3×3, 16 фильтров → ReLU → MaxPool 2×2
11×11×16 → 5×5×16 → Flatten 400 → Dense 64 → ReLU → Dense 10 → Softmax
```

При обучении используются Adam, cross-entropy, batch size 128 и небольшие случайные повороты, сдвиги и изменения масштаба. Вход — яркость пикселей от 0 до 1. Разбиение train/validation воспроизводится с seed 42. Тест не участвует в выборе эпохи.

В браузере нарисованная цифра обрезается по рамке, вписывается в 20 × 20 и центрируется по центру масс на поле 28 × 28. Готовые примеры MNIST передаются модели напрямую, без повторного изменения размера. При дорисовывании пример обрабатывается как пользовательский рисунок.

## Повторить обучение

Нужен Python 3.11+ и интернет для первоначальной загрузки MNIST и зависимостей:

```sh
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r training/requirements.txt
python training/train.py --epochs 8
```

Проверенная среда: Python 3.11, PyTorch 2.9.0+cpu, NumPy 2.1.3. Обучение поставляемой версии заняло около трёх минут на текущем CPU; на других устройствах время отличается. Скрипт обновляет `assets/model.json`, `assets/weights.bin` и `assets/examples.json`. Для проверки версии после обучения запусти `npm test`. Даже с фиксированным seed результат может немного отличаться между версиями библиотек и оборудованием.

## Проверка

```sh
npm test
```

Тесты сопоставляют JavaScript-вычисления с сохранёнными выходами PyTorch на 30 образцах (допуск 0,00002), проверяют контрольную сумму весов, согласованность метрик и обработку повреждённой модели. Это проверка реализации, а не замена независимому тесту на 10 000 изображений, который выполняет Python-скрипт.

## Ограничения

98,42% — точность на тесте MNIST, а не обещание точности для произвольного почерка. Сеть знает только десять классов и не умеет надёжно отличать цифру от рисунка предмета. Softmax может давать высокий балл ошибочному ответу. Пустой холст обрабатывается отдельно и не передаётся сети. Слишком короткий штрих также может не пройти проверку пустого ввода. Цифры с необычной толщиной, несколько цифр и рисунки у края холста могут распознаваться хуже.
